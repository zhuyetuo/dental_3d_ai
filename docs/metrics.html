评分卡里的每个数字是什么意思

指标说明

评分卡就是给生成的牙冠打分：把一颗真牙挖掉，让模型重新生成，再量生成的牙。每个指标一句话讲清楚。 同一套量法也量天然牙，天然牙的数就是及格线。单位都是毫米（mm）或平方毫米（mm²）。 越小越好 越大越好 越接近天然牙越好

一图看懂几个关键量

形状误差Chamfer = 所有灰线的平均长度（整体差多少）；Hausdorff = 最长的那根（最差的地方差多少）。
和对颌的关系间隙 = 离对颌最近的地方有多远；负数 = 穿进对颌（红色），真做出来会咬不下去。
和邻牙的关系和两边邻牙要刚好贴上：有缝会塞食物，挤进去戴不进去。
牙尖和中央窝咬合面上的“山顶”和“谷底”。位置偏差 = 生成的和真牙的差多远；深度 = 山顶到谷底多高。

形状：和被挖掉的真牙像不像

指标一句话方向参考（11-14）
形状误差（Chamfer）生成的牙表面和真牙表面平均差多远。最常用的一个数越小越好现在 0.27 mm
RMSE也是平均差多远，但大的偏差算得更重（偏差先平方再平均再开方）越小越好0.33 mm
Hausdorff差得最远的那一处差多少，看“最坏的地方”越小越好1.2 mm
F-score@0.3 / 0.5表面上有多大比例的点和真牙差在 0.3 / 0.5 mm 以内越大越好—
高度差（ref_top）生成的牙最高点比真牙高（正）还是低（负）多少接近 0—

咬合面细节：牙尖和窝像不像

指标一句话方向天然牙 / 现在
牙尖位置偏差生成的牙尖和真牙的牙尖平均差多远（自动找“山顶”，一一配对后量距离）越小越好— / 0.84 mm
中央窝位置偏差咬合面最低的“谷底”和真牙的差多远越小越好— / 0.86 mm
牙尖到窝的深度咬合面起伏有多大。太浅 = 牙面太平，咬东西不好使接近天然牙2.00 / 1.98 mm
牙尖个数（及和真牙的差）找到几个牙尖，和真牙数量差几个差 0 最好2 / 2
细节量（detail）去掉大的起伏后，剩下的细小凹凸有多少（沟纹够不够）接近天然牙0.26 / 0.27

牙尖、中央窝是自动找的，低矮的磨牙牙尖偶尔会漏掉，这几个数有一点噪声。

咬合：和对面的牙咬得对不对

指标一句话方向天然牙 / 现在
和对颌的间隙牙冠离对面的牙最近处有多远；负数 = 穿进去了按设计值（0 或 0.3）0.06 / 0.00 mm
穿入对颌 > 0.1 mm 的比例多少颗牙冠戳进了对面的牙。真做出来要磨，或者咬不下去越小越好13% / 0%
没咬上（间隙 > 0.2 mm）的比例多少颗牙冠完全碰不到对面的牙，咬东西不出力越小越好24% / 2%
咬合接触面积离对颌 0.2 mm 以内的面积。太大 = 整片贴死，太小 = 没咬上接近天然牙2.1 / 4.5 mm²
虚拟咬合纸面积模拟牙医用的咬合纸：离对颌 0.1 mm 以内会被“染色”的面积接近天然牙0.36 / 1.9 mm²

邻接和位置：和左右邻牙合不合

指标一句话方向天然牙 / 现在
近中 / 远中间隙和前面 / 后面那颗牙最近处多远；负数 = 挤进去了略小于 0−0.06 / −0.05 mm
邻接有缝 > 0.15 mm 的比例至少一边没贴上的牙冠占多少，会塞食物越小越好6% / 3.5%
挤进邻牙 > 0.15 mm 的比例至少一边挤进邻牙的牙冠占多少，会戴不进去越小越好20% / 21%
相对邻牙的高度牙冠比两边邻牙高（正）还是低（负）多少，看是否“齐”接近 00.00 / 0.00 mm
颊舌向错位（arch_offset）牙冠是不是偏向脸颊或舌头一侧，偏出牙弓越小越好—

天然牙也有 13% “穿入对颌”、20% “挤进邻牙”：不是真的穿进去，是口扫拼合和自动分割边界的误差（约 ±0.2 mm），所以阈值都放在 0.1–0.15 mm 以上，看的时候和天然牙那一列比。

训练日志里的两个数

指标一句话方向
深度误差（depth_mae）扩散模型在“深度图”上逐像素和真牙差多少，训练中途快速看效果用；正式结论看评分卡越小越好
重合度（mask_iou）生成的牙冠轮廓和真牙轮廓重叠的比例，1 = 完全重合越大越好
T-mIoU（分割）分割出来的每颗牙和标准答案的重叠比例，取平均。分割论文都用它越大越好

怎么看一次结果好不好

  1. 先看整体形状：形状误差、牙尖 / 中央窝偏差不能变差；
  2. 再看和邻牙、对颌合不合：穿入、没咬上、有缝、挤进去这几个比例，越接近天然牙越好；
  3. 最后看咬合面细节：牙尖到窝的深度、细节量接近天然牙。
