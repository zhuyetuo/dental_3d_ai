这个方向走到哪了：里程碑和最新进展

分割、牙冠生成、颈缘线三条线，按年份记学术界的代表工作和产业界的产品节点；最后和我们自己的数字放在一起比。 每次大的迭代前查一遍新论文，每月做一次全面更新。厂商数字都是厂商自己说的，单独标出。

一眼看现在（2026-11）

分割
~92–93%
公开集 T-mIoU 已饱和（TeethSplineSeg 92.6%、3DTeethSAM 91.9%）；难点在跨来源、缺牙、拥挤
牙冠生成
扩散 / 模板变形
从点云补全 → 模板变形 / 扩散；咬合面细节仍是公认难点；最好的（DCrownFormer+）已商业化收回代码
颈缘线
~0.1–0.2 mm
多数病例达到技工一致水平；数据都在技工所手里，公开的只有切牙 52 例 + 各牙位 78 例
产业
单冠 1–2 分钟
3Shape Automate、exocad AI Design、Dentbird、先临 AI Design；exocad 3.3 已支持最多 3 颗相邻后牙

里程碑时间线

时间方向工作 / 产品意义
2019–2021
2019–2020分割MeshSegNet（MICCAI 2019 / TMI 2020）最早一批直接在口扫网格上做逐面分割的深度网络
2021分割TSegNet（MedIA）先找牙齿中心再分实例，“实例分割”路线的起点
2022
2022分割 / 数据Teeth3DS + 3DTeethSeg'22 挑战赛（MICCAI）第一个大规模公开口扫标注数据（1800 个扫描）；TGNet 拿第一，成为后来的基线
2022生成ToothCR（PAKDD）补全 + 重建两阶段的早期牙冠生成
2023
2023生成DMC（MICCAI）预备体 + 邻牙 + 对颌 → Transformer 点云补全 + 可微泊松重建；第一次把“上下文 + 网格输出”做完整
2024
2024生成DCrownFormer（MICCAI）预备体 + 对颌直接出网格
2024颈缘线Adaptive Point Learning（Alsheghri 等）颈缘线当点云生成，带不确定性
2024关键点 / 数据Teeth3DS+ / 3DTeethLand'24第一个公开的 3D 牙齿关键点数据集（牙尖、窝等），评估咬合面形态有了标准
—产业3Shape Automate（上线年份待核）云端 AI 设计服务，后牙单冠约 90 秒、2–3 美元（厂商）；2024 年扩展到前牙
2024产业exocad AI Design（DentalCAD 3.2）桌面 CAD 内置 AI 单冠建议，约 2 分钟
2025
2025分割CrossTooth（CVPR）多视图渲染特征 + 点云，边界更准；代码和权重公开
2025生成DCrownFormer+（MedIA）改善咬合面细节；技术转让给韩国公司，代码不再公开
2025生成VBCD（MICCAI）、ToothForge（IPMI）体素粗到细 + 牙位提示；谱域生成，毫秒级
2025颈缘线Alsheghri 等，全牙位（CBM）1113 个真实预备体，78 例中 70 例在 200 μm 内
2025-09产业先临三维 AI Design扫描仪厂商补齐设计；宣传单冠约 60 秒（厂商）
2025-12生成CrownGen（arXiv 2512.21890）牙齿级点云扩散，一次生成多颗；26 例临床研究不劣于技工
2026
2026 初分割3DTeethSAM（AAAI）多视图渲染 + SAM2，T-mIoU 91.9%，第三磨牙明显提升
2026-01临床评价exocad / 3Shape Automate / Dentbird 对比（Dental Materials）按形态、咬合接触、断裂强度、边缘密合比较三家；多篇综述提醒咬合方案要人复核
2026-03生成MADCrowner（MedIA，Apache-2.0）颈缘线分割 + 模板变形；4602 名患者的技工设计数据；和我们的模板路线最接近，作者把扩散列为下一步
2026-03生成ToothCraft（VISAPP）以局部牙弓为条件的 SDF 扩散，用合成残缺牙训练；有权重（AGPL）
2026-03分割TSegAgent（MICCAI）SAM3 + 视觉语言模型零样本；自报 93.4%，他人实测开源版差很多
2026-05生成分类引导的局部口扫 → 牙冠方案（arXiv 2605.15241）检索 + 拟合路线，只有定性结果
2026-06生成深度谱模型（arXiv 2606.31293）ToothForge 的后续，形状生成更稳健
2026-08分割TeethSplineSeg（B 样条牙弓坐标）PTv3 + 牙弓连续坐标，T-mIoU 92.6%，训练 2 小时、推理 0.8 秒
2026产业exocad DentalCAD 3.3AI 支持最多 3 颗相邻后牙冠 / 3 单位桥，加上咬合垫 AI
—生成CrownFusion（项目页 crownfusion.github.io）扩散模型生成牙冠；我们的径向深度图表示参考了它的“把 3D 牙冠变成 2D 图再用图像扩散”的思路

技术路线怎么演进的

几何 / 模板对侧镜像、标准牙库 + 手动调整（传统 CAD）
点云补全DMC、ToothCR：上下文 → 补出缺的牙
模板变形MADCrowner、我们的 D：模板牙按上下文变形，形状稳
扩散生成CrownGen、ToothCraft、CrownFusion：细节更像真牙，但形状会偏
组合我们 11-14：模板变形出形状 + 扩散补细节

分割已经从“专用点云网络”走到“多视图渲染 + 视觉基础模型”和“点云 + 牙弓结构先验”两条路； 颈缘线从几何规则走到网格二分类 / 点云生成。三条线的共同瓶颈都是数据：技工设计好的牙冠和颈缘线只在技工所和企业手里。

我们和他们比

方向我们（2026-11-14）别家公开的最好数字能不能直接比
分割T-mIoU 87.4%（公平测试集 174 个）；真实缺牙检出 55%TeethSplineSeg 92.6%、3DTeethSAM 91.9%测试集划分不同，要在同一批扫描上跑他们的权重才算数（有代码和权重，待做）
牙冠生成和天然牙 Chamfer 0.27 mm；邻接有缝 3.5%；高度和天然牙一致DMC Chamfer 0.062（归一化坐标）；CrownGen 临床不劣于技工不能：DMC 不是毫米、真值是技工设计；我们的真值是天然牙。CrownGen 有代码和示例数据，可以拿来在我们的评分卡上跑
颈缘线误差中位数 0.038–0.053 mm（单独代型）Alsheghri 70/78 例在 200 μm 内；MADCrowner Hausdorff 0.33 mm量法不同（中位数 / 比例 / 最大误差）；我们还没在整颌口扫上测
速度一颗牙整单约 1.5 分钟（CPU，含分割）3Shape 90 秒、先临 60 秒（厂商）同一量级
