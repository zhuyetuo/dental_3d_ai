这个方向走到哪了：里程碑和最新进展

分割、牙冠生成、颈缘线三条线，按年份记学术界的代表工作和产业界的产品节点；最后和我们自己的数字放在一起比。 每次大的迭代前查一遍新论文，每月做一次全面更新。厂商数字都是厂商自己说的，单独标出。

几何 / 模板对侧镜像、标准牙库 + 手动调整（传统 CAD）

分割已经从“专用点云网络”走到“多视图渲染 + 视觉基础模型”和“点云 + 牙弓结构先验”两条路； 颈缘线从几何规则走到网格二分类 / 点云生成。三条线的共同瓶颈都是数据：技工设计好的牙冠和颈缘线只在技工所和企业手里。

基础模型的演进：牙齿分割（点云 / 网格分割网络）

上面的时间线是“牙科这个应用”的进展；这里是它底下用的通用网络结构。牙科论文基本是把通用 3D 网络的最新一代拿来，加上牙弓先验。

年份基础模型核心思想在牙科里的代表
2017PointNet / PointNet++直接吃点云；逐点 MLP + 全局池化，++ 加了分层局部特征早期牙齿分割基线
2019DGCNN（EdgeConv）每层按特征重新找 k 近邻、在边上做卷积，局部几何更强MeshSegNet 一类、DilatedToothSegNet；我们现在用的就是这一代（加了一层全局注意力）
2021Point Transformer（v1）/ PCT局部邻域里做自注意力TGNet 的思路同期；CrossTooth（CVPR 2025）用 PTv1
2022Point Transformer v2分组向量注意力、网格池化，更快更准—
2023–2025SAM / SAM2 / SAM3（图像分割基础模型）海量图像预训练的通用分割；3D 上用“多视角渲染 → 2D 分割 → 投回网格”3DTeethSAM（SAM2）、TSegAgent（SAM3）
2024Point Transformer v3（PTv3）点按空间曲线排序后做序列注意力，感受野大、速度快，能直接吃十几万点TeethSplineSeg（92.6%，目前公开最好之一）
2025Sonata 等 3D 自监督预训练PTv3 在大量无标注点云上自监督预训练，再微调牙科里还没见到

基础模型的演进：牙冠 / 3D 形状生成

年份生成方法核心思想在牙科里的代表
2018 以前模板 / 统计形状模型牙库里挑标准牙，缩放、变形贴进缺隙（传统 CAD 的做法）3Shape、exocad 的牙库；我们的“几何方法”
2014–2020GAN生成器和判别器对抗；生成快，但训练不稳、容易模式坍塌早期 AI 牙冠（2D 深度图 GAN），2026 仍有 GAN 牙冠论文
2018–2021点云补全：PCN、FoldingNet → PoinTr（Transformer，2021）把“缺一颗牙”当成点云补全；Transformer 编码上下文DMC（2023，PoinTr）、DCrownFormer（2024）、我们的 D 是这一类的模板变形版本
2020–2022扩散模型：DDPM、DDIM；3D 上 PVD、LION从噪声一步步去噪；多样性和细节最好，代价是采样慢CrownGen（2025，点云扩散）、ToothCraft（2026，SDF 扩散）、我们的径向深度图扩散（U-Net）
2023DiT（Transformer 当扩散的去噪网络）、3DShape2VecSet（形状潜空间）去噪网络从 U-Net 换成 Transformer；先把形状压成一组潜向量再在潜空间扩散牙科里还很少
2023–2024Flow Matching / Rectified Flow扩散的“直线版”：学从噪声到数据的速度场，采样步数少、训练更稳；SD3（2024）开始成为主流牙科里还没见到
2024–2025大规模 3D 生成基础模型：CLAY、TRELLIS、Hunyuan3D 2.0形状潜空间 + Flow Matching + DiT，在百万级 3D 模型上训练可以借它们的结构；牙科数据量（几万颗牙）训这么大的模型不够，要么小号版，要么在它们的权重上微调
Transformer 和 Diffusion 不是二选一
Transformer 是网络结构（怎么算），Diffusion / Flow Matching 是生成方法（怎么训练、怎么从噪声变成牙）。 现在最新的做法是两者合起来：Flow Matching + Transformer（DiT），在形状潜空间里生成。
扩散旧了吗？
生成方法本身没过时：Flow Matching 是扩散的改进版，思路一脉相承。我们旧的是具体组合： DDPM 式扩散 + U-Net + 2D 径向深度图，大约是 2021–2022 年的配置。升级路线：U-Net → DiT，扩散 → Flow Matching（步数少、快）， 2D 径向图 → 3D 形状潜空间（窝沟分辨率更高）。已写进想法清单。

分割为什么差 5 个点、怎么补

我们TeethSplineSeg（92.6%）/ TGNet
基础网络DGCNN（2019）+ 一层全局注意力PTv3（2024）/ 两阶段点网络
每个口扫用多少点8000 点，再插值回十几万个顶点TGNet 24000 点 + 边界附近再采样；PTv3 可以直接吃全分辨率
牙和牙龈的边界没有专门处理（插值后边界发糊）TGNet 第二阶段专门细化边界
牙弓先验只在编号纠错（后处理）里用B 样条牙弓坐标直接进网络
多训练有没有用11-13 在 4090 上接着训了一晚，常规口扫的分数基本没动（96.6% → 96.6%，T-mIoU 86.8% → 87.4%）：瓶颈是模型结构和点数，不是训练时间
测试集我们用两套划分的交集 174 个（公平测试集）；论文数字用各自的划分，有一部分差距是测试集不同造成的，要在同一批扫描上跑他们的权重才知道真实差距

结论：用现有数据，换更好的模型比训更久更有用。顺序：① 先在公平测试集上直接跑 TeethSplineSeg、CrossTooth 的公开权重（几个 GPU 小时，量出真实差距）； ② 用 PTv3（Pointcept）在我们的缓存上重训，点数加到全分辨率，保留模拟缺牙的增强（论文报告 4090 上约 2 小时）；③ 加牙弓坐标特征和边界细化。
