## 牙冠生成与邻接复核

- 条件残差续训在固定 1,189 个牙位上把深度误差约从 0.411 降到 0.395 mm。首批 25 颗牙的咬合调整结果中，外形误差由 0.2844 升到 0.2853 mm。条件细节、咬合约束和牙库末端牙各向异性对照也保留在汇总中。Flow Matching 尝试因起点检查点的类别嵌入尺寸不兼容而在加载时退出。
- 34 位患者、64 颗牙的三组对照中，咬合调整后的外形中位误差为纯形状 0.263 mm、残差续训前 0.309 mm、续训后 0.296 mm。续训后，对颌穿入从 1 颗降到 0 颗，旧评分标记的邻牙挤压从 11 颗增到 13 颗。
- 邻牙目标间距从现有 −0.03 mm 改到 0 和 +0.05 mm 后，旧评分标记的挤压为 12、9、5 颗，邻牙缝隙过大为 2、2、4 颗，形状误差接近。0 mm 组新增 1 颗对颌穿入。
- 第一次局部退让将原队列的挤压从 12 颗降到 10 颗，在另 12 位患者的 24 颗牙上仍为 5 颗。精确三角面投影只找回了 7 颗漏检中的 1 颗，没有消除挤压。放宽法向和连续射线筛选，在诊断样本中能找回 3 颗。
- 几何复核重建 88 颗基线冠、176 个邻面，生成 19 组私有截面。旧评分标记的 19 个邻面中，8 个有远离开放边缘的三角面相交，11 个的相交集中在开放边缘。复查深度和面积后，只有 1 个邻面在三次采样中均达到研究阈值，深度峰值约 0.25 mm。以三角面相交引导的退让没有通过成品复查。
- 离线评分通过 [eval_crown](../../ml/dental_ai/eval_crown.py) 的 --proximal-audit 输出边界相交、低于深度面积阈值的面内相交、以及有深度和面积支持的穿入。176 个邻面的深度和面积与独立计算一致。
- 正式批量评估计划 48 位患者。46 位的 88 颗牙在三个模型、四种生成模式下有配对结果。另有 5 个目标牙位对三组四种模式均生成失败。要求对颌接触的模式下，纯形状、续训前和续训后的外形误差分别为 0.290、0.323 和 0.304 mm，未接触对颌分别有 2、2、5 颗。额外 12 位患者中，残差续训前后的中位形状误差为 0.351 和 0.354 mm。新版评分在这批未检出达到深度面积阈值的邻牙穿入，先前那例深穿入的牙位本批未被抽到。

## 颈缘线训练与成品敏感性

1. **模拟数据混合训练。** 44 个模拟留出样本的平均误差由旧数据对照的 0.442 降到 0.219 mm，15 个真实代型上由 4.491 升到 4.823 mm。其他 11 个切牙代型上，混合模型平均误差 4.076 mm，代型模型为 0.143 mm。采用分场景评估。
2. **真实代型的裁剪增强。** 使用 85 个训练、19 个开发代型，两组各训练 8 轮，选中第 2 轮。完整切牙代型的常规与裁剪增强平均误差为 0.144 和 0.133 mm，裁剪切牙为 0.227 和 0.181 mm。完整公开代型为 0.109 和 0.091 mm，裁剪公开代型为 0.335 和 0.260 mm。完整测试输入共 26 个代型，裁剪组有 19 个代型的 22 个有效裁剪。下一步用真实局部预备体口扫验证。
3. **终止线误差传递。** 固定同一外冠初始网格、预备体和对颌，只改变终止线。130 组里有 122 组的四臂均得到封闭冠。7 组固定外冠生成失败，1 组真值参考几何失败。独立测试集 44 组中有 42 组可比较。以内表面边缘环与同一模拟参考线的双向距离评估边缘偏差。

| 终止线 | 测试组成品平均边缘偏差的中位数 | 成品边缘偏差 P95 的中位数 |
| --- | ---: | ---: |
| 几何自动检测 | 0.235 mm | 0.641 mm |
| 模拟真值 | 0.073 mm | 0.210 mm |
| 咬合侧偏移 0.30 mm 后吸附牙面 | 0.125 mm | 0.241 mm |
| 根尖侧偏移 0.30 mm 后吸附牙面 | 0.154 mm | 0.402 mm |

两种偏移吸附后到真值的平均线距离约为 0.12–0.13 mm。固定参考带外的内表面间隙中位约 0.029 mm，薄区比例无稳定变化。结论适用于模拟预备体。相关方法参考 [DentalGEN](https://www.nature.com/articles/s41746-026-03236-7) 的成品分项评估与 [补充材料](https://static-content.springer.com/esm/art%3A10.1038%2Fs41746-026-03236-7/MediaObjects/41746_2026_3236_MOESM1_ESM.pdf) 的边缘线双向距离。

## 复现

在仓库根目录使用已安装项目依赖的 Python 和 CUDA。把本地数据、缓存和起始权重放在命令及脚本声明的路径。建议为每轮设一个新的输出目录。汇总文件只包含聚合指标，输入网格和逐例结果保存在原数据环境。

    export PYTHONPATH="$PWD/ml"
    export OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 MKL_NUM_THREADS=2

预备体敏感性实验输入为已配对的模拟预备体归档，包括患者隔离的清单、每例 context.npz 和各制备 variant.npz。外冠采用仓库的形状模型，回退模板仍在患者制备体内按同一输入固定。

    DENTAL_SYNTHETIC_PAIRS=runs/synthetic_prep_pairs_v1_20261121 \
      DENTAL_PREP_STUDY_OUT=runs/replay_prep_sensitivity \
      python scripts/research/prep_margin_sensitivity.py

代型裁剪微调用 [脚本](../../scripts/research/margin_crop_finetune.py)中列出的两个真实代型训练目录和初始 margin.pt。

    DENTAL_MARGIN_CROP_OUT=runs/replay_margin_crop \
      python scripts/research/margin_crop_finetune.py

Poseidon3D 需要现有训练缓存 data/deep_cache、Poseidon3D 官方训练与测试导出、常规测试集 data/fair_test 和初始 deep.pt。开发集的导出与缓存可使用仓库现有命令。

    export DENTAL_POSEIDON_OUT=runs/replay_poseidon
    python -m dental_ai.datasets poseidon3d --zip /path/to/poseidon3d.zip \
      --split validation --out "$DENTAL_POSEIDON_OUT/validation_meshes"
    python -m dental_ai.segmentation.deep cache --extra-dir "$DENTAL_POSEIDON_OUT/validation_meshes" \
      --out "$DENTAL_POSEIDON_OUT/validation_cache"
    python scripts/research/poseidon_finetune.py
    python scripts/research/poseidon_evaluate.py

邻接几何复核会写入逐牙 CSV 和 summary.json。现有的咬合调整、无咬合调整与无对颌输入模式可用相同参数比较。

    python -m dental_ai.eval_crown --zip /path/to/Bite2Text.zip --truth /path/to/report_truth.json \
      --seg-model models/segmentation/deep.pt --gen-model models/generation/toothgen_open.pt \
      --patients 48 --per-jaw 1 --workers 6 --proximal-audit --out runs/replay_proximal
